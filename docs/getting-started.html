Getting Started

From clone to first booking in five minutes

Prerequisites

  • Node.js 18+
  • Git
  • A modern browser (Chrome, Firefox, Safari, Edge)

1. Clone the Repository

git clone https://github.com/NeoDonkey/NeoDonkey-ERP.git
cd NeoDonkey-ERP

2. Run the Demo

node demo/sarah.mjs

This creates a complete company ("Sarah's Bike Shop"), books a goods receipt through the company's own written rules, has the company refuse an invalid one, changes the business by editing a sentence — and then hands the folder to real git and real ssh-keygen and asks them what they think.

3. Verify the Output

cd demo-company/
git fsck --strict          → clean
git status --porcelain     → empty      (it is simply a folder)
git log --show-signature   → G          (good signature, on every commit)

G is git's own verdict: good signature. Software written by other people over twenty years accepts our commits as genuine and verifies our signatures.

4. Run the Tests

npm test

The full test suite runs in about 30 seconds and covers the kernel, Polism grammar, CRDT merge, cryptographic signing, and DATEV serialization.

5. Start the UI

npm run ui

Open http://localhost:8080 in your browser. The UI is generated from the operating model — what you see depends on the roles defined in your company.

Folder Structure

your-company/
├── index.html              ← the app shell. served, not double-clicked
├── runtime/                ← the software, readable, in the repo, next to the data
├── operating-model/        ← your company, as text. this IS the program.
│   ├── processes/          ← goods-receipt.md, invoice-issuance.md …
│   ├── organisation/       ← the roles and who may authorize what
│   ├── locations/          ← warehouses, offices, shops
│   ├── information/        ← charts of accounts, tax codes
│   ├── suppliers/          ← supplier master data
│   └── management-system/  ← quality, safety, compliance
├── documents/              ← the facts: articles, orders, invoices, stock
└── .git/                   ← the truth: signed, append-only, yours

Creating Your First Company

Companies are created by the kernel.js module. The process:

  1. Generate an Ed25519 keypair for the founder
  2. Write the operating model (processes, organisation, locations)
  3. Initialize the git repository
  4. Sign the initial commit

Posting Your First Booking

Bookings are created through the Polism rule engine:

  1. The user initiates a Create goods-receipt action
  2. The kernel validates the action against the operating model
  3. If valid, a new document is created in documents/
  4. The document is committed to git with the founder's signature
  5. The read index is updated to reflect the new state
