Procurement & Compliance FAQ

What does "self-hosted" mean for our compliance team?

NeoDonkey runs entirely in your browser using the Origin Private File System. No data leaves your device unless you explicitly sync it to your own git remote. For SOC 2 or GDPR audits, you control the entire data lineage.

How do we back up our data?

Your entire company is a git repository. Back it up the same way you back up code: git push to GitHub, GitLab, or your private Gitea instance. Every transaction is cryptographically signed and immutable.

What if we need to migrate from SAP/Odoo?

NeoDonkey imports standard CSV/JSON formats. Most customers migrate master data in 2-3 days. Historical transactions can be imported as signed git commits, preserving your audit trail.

Who maintains the software?

NeoDonkey is EUPL-1.2 licensed open source. The core team maintains the project, but you're never dependent on us. You can fork, modify, and self-maintain. Or hire any JavaScript developer, no proprietary certifications required.

Is there a paid "Enterprise" version?

No. There is only one version: the open source version. We don't hold features hostage. If you need managed hosting or custom development, contact us for consulting, but the software is always free.
