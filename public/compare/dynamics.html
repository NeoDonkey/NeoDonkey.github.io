Frequently Asked Questions

Is NeoDonkey a real alternative to Microsoft Dynamics 365?

Yes. NeoDonkey provides core ERP functionality (general ledger, accounts payable/receivable, inventory, procurement) that covers 80% of what most SMEs use Dynamics for. The trade-off: you give up Microsoft's ecosystem integration (Office 365, Power BI, Azure) in exchange for zero cost and complete data sovereignty.

How does implementation time compare?

Dynamics 365 implementations typically take 6-12 months with a Microsoft partner. NeoDonkey can be operational in under 1 hour: open the browser, import your chart of accounts, and start transacting.

Can I migrate my Dynamics data to NeoDonkey?

Yes. NeoDonkey imports standard CSV/JSON formats. Export your master data from Dynamics (customers, vendors, chart of accounts) and import it directly. Historical transactions can be imported as signed git commits.

What about Power BI reporting?

NeoDonkey exports to CSV/JSON which can be imported into any BI tool (Metabase, Apache Superset, Tableau). For real-time dashboards, the headless API allows direct querying. You lose Power BI's native integration but gain tool flexibility.
