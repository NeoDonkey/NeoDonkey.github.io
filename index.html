How it works

Log in, and the company is already there

The whole of it happens on your machine, in the order below, and you can watch it happen in about ten seconds.

1

You type your name

That is the entire log-in. The browser generates an Ed25519 key pair whose private half cannot be exported, and that key is who you are from then on.

2

A company is written

The runtime reads an operating model — processes, roles, record types, written as markdown — and commits a working company into a git repository in your browser.

3

You work, and it commits

Every change is an atomic, signed commit. The log is a real git log, and the software is just something that reads and writes the folder.

Why NeoDonkey

The properties fall out of the architecture

The core is headless and dependency-free. This site is one head among many — it exists to show what a richer one can do, and the plain one ships with the product.

Headless by construction

A zero-dependency ES-module core with no framework and no vendor. Attach the vanilla UI, this site, or a head of your own — the core cannot tell the difference.

Git is the database

Not "backed up to git" — the repository is the system of record, with history, signatures and merges that any git client on earth can read.

Signed, not permissioned

Every commit carries the author's signature. Authority is something you can verify from the repository, not a row in somebody else's access table.

A Copilot with nowhere to send anything

Where the hardware allows, a quantised model runs on your GPU, reads the repository, and answers by generating an interface. No API, no key, no request.

Nothing to be locked out of

The repository is a folder. Copy it to a USB stick and the whole system — data, history and the code that reads it — goes with you.

European, and licensed to stay that way

EUPL-1.2. No servers to host, nothing to scale, nothing to pay for — for you or for us.

In-browser Copilot

Ask your company a question. Watch the interface build itself.

A small quantised model is downloaded once and compiled to your GPU's own shaders. It reads the repository at its current commit and answers with A2UI — a JSON description of an interface, which this site turns into DOM. It is offered only where the hardware supports it, and it is never required.

  • Runs on your own graphics hardware over WebGPU
  • Output constrained by a grammar, then sanitised, then rendered
  • Weights fetched once, kept in this browser, deletable in one click

Open a company in ten seconds.

No account, no install, no server. Type your name, and a signed git repository with a working company in it appears in this browser.
